# Tiny GPT from Scratch

A hands-on Python project exploring the fundamentals of
GPT-style language models and Transformer architecture.

## Project Components

- Transformer blocks implemented in Python
- Tokenizer implementation and vocabulary
- Text corpus for learning and experimentation
- Understanding self-attention and GPT architecture

## Technologies

- Python
- PyTorch
- Tokenization

## Objective

Build a foundational understanding of how GPT-style
language models work internally, including tokenization,
embeddings, attention mechanisms and model training.
